# Rule-Based Chatbot using Python

## Project Description

This project is a **Rule-Based Chatbot** developed using Python.
The chatbot interacts with users and provides responses based on predefined rules and keyword matching.

It demonstrates the basic concept of **Natural Language Processing (NLP)** and how a chatbot can simulate simple conversations.

This project was created as part of the **CodSoft Internship Program**.

---

##  Objectives

* Build a simple chatbot using Python
* Understand rule-based conversation flow
* Implement conditional logic for chatbot responses
* Learn basic NLP concepts

---

##  Technologies Used

* Python
* Conditional Statements
* Dictionary-based responses
* Random module
* Datetime module

---

##  How It Works

1. The user enters a message.
2. The chatbot processes the input text.
3. The program checks for keywords or patterns.
4. A predefined response is selected.
5. The chatbot prints the response.
